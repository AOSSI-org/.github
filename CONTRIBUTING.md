# Contributing to AOSSI

AOSSI is a space hardware project developed in the open. It's early, and help is welcome.

## Licensing

Licensing for AOSSI projects is being finalized. It will be published before any outside contributions are merged. Pull requests won't be merged until then. Issues, ideas and discussion are welcome now.

Blog posts in aossi-blog are under that repo's LICENSE.

## Where things go

- **Questions, ideas and show-and-tell:** [Discussions](https://github.com/orgs/AOSSI-org/discussions).
- **Bugs, concrete feature requests and docs fixes:** open an issue in the repository it's about, using one of the forms.
- **About AOSSI:** [aossi.org](https://aossi.org/).

## Making a change

1. Check open issues and Discussions first, so work isn't duplicated.
2. For anything bigger than a small fix, open an issue or a discussion before you start.
3. Fork the repository, make the change on a branch, and open a pull request using the template.
4. Keep each pull request to one change. Say how you checked it.

## Ground rules

- Be direct and be kind. Criticize the work, not the person.
- Don't post personal information, yours or anyone else's.
- Don't post keys, passwords or other secrets.
- Space hardware can fall under ITAR and EAR export rules. Don't post export-controlled technical data. If you're not sure, ask in Discussions first, without the details.
